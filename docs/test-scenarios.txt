# Test Scenarios for Home Credit LAP Voice Agent

Use these scenarios to thoroughly test the agent before production deployment.

## Scenario 1: Perfect Happy Path

**Objective:** Test standard qualification flow with all criteria met

**Customer Responses:**
1. Agent: Introduction
   - Customer: "Yes, please go ahead"

2. Agent: Property type?
   - Customer: "It's a residential property"

3. Agent: Ownership?
   - Customer: "It's in my name only"

4. Agent: Original documents?
   - Customer: "Yes, I have all the original papers"

5. Agent: Loan amount needed?
   - Customer: "I need 50 lakhs"

6. Agent: Occupation?
   - Customer: "I'm salaried, working in an IT company"

7. Agent: Income receipt method?
   - Customer: "My salary comes through bank transfer"

8. Agent: Property market value?
   - Customer: "The property is worth around 1.2 crore"

9. Agent: Preferred tenure?
   - Customer: "I'd like a 10-year loan"

**Expected Outcome:**
- All information collected ✅
- Agent confirms all details ✅
- Preliminary qualification confirmed ✅
- Handoff to senior expert scheduled ✅

## Testing Checklist

### Core Functionality
- [ ] All 8 data points collected successfully
- [ ] Information validated with customer
- [ ] Preliminary qualification determined
- [ ] Handoff to senior expert confirmed

### Edge Cases
- [ ] Amount over ₹75 lakh handled (both accept and decline)
- [ ] Missing documents handled
- [ ] Busy customer handled (callback scheduled)
- [ ] Existing loan scenarios handled
- [ ] Unclear answers clarified
- [ ] Out-of-order information accepted
- [ ] Interruptions handled gracefully

### Compliance
- [ ] No promises of final approval
- [ ] No specific interest rate quotes
- [ ] No guaranteed disbursement commitments
- [ ] Clear preliminary nature communicated
- [ ] Proper expectations set

### User Experience
- [ ] Professional and warm tone
- [ ] Patient with clarifications
- [ ] Empathetic to customer constraints
- [ ] Clear and concise communication
- [ ] Smooth handoff process

### Technical
- [ ] Audio quality acceptable
- [ ] Response latency < 2 seconds
- [ ] Handles interruptions without breaking
- [ ] Post-call data extraction accurate
- [ ] All fields populated correctly
