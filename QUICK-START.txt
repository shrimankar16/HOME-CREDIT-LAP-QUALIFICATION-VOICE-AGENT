STEP 2: CREATE THE AGENT (5 minutes)
===============================================================================

OPTION A: DASHBOARD (Recommended for First Time)
-------------------------------------------------

1. LOG INTO RETELL DASHBOARD
   https://dashboard.retellai.com/

2. CREATE NEW AGENT
   - Click "Create Agent"
   - Select "Single Prompt Agent"

3. BASIC CONFIGURATION
   - Name: Home Credit LAP Agent
   - Language: English (en-US)
   - Model: Claude 3.5 Sonnet
   - Voice: Cimo (or any professional voice)
   - First Speaker: Agent

4. COPY THE PROMPT
   - Open "config/agent-prompt.txt" from this folder
   - Copy ALL content (Ctrl+A, Ctrl+C)
   - Paste into the System Prompt box in Retell

5. VOICE SETTINGS
   - Speed: 1.0
   - Temperature: 1.0
   - Enable Backchannel: ON
   - Add backchannel words: "yes", "okay", "I see", "understood"

6. ADVANCED SETTINGS
   - Expand "Agent Handbook" section
   - Turn ON these options:
     ✅ Default Personality
     ✅ Conversational Personality
     ✅ Natural Filler Words
     ✅ High Empathy
     ✅ Echo Verification
     ✅ Speech Normalization
     ✅ Smart Matching

7. BOOSTED KEYWORDS (Optional but Recommended)
   Add these keywords for better speech recognition:
   - Home Credit
   - lakh, lakhs
   - crore, rupees
   - residential, commercial

8. SAVE DRAFT

===============================================================================
COMMON FIRST-TIME ISSUES
===============================================================================

ISSUE: Agent sounds robotic
---------------------------
Fix: 
- Enable "Natural Filler Words" in Agent Handbook
- Try a different voice (Eleven Labs voices are more expressive)

ISSUE: Agent gets interrupted too easily
----------------------------------------
Fix:
- Lower Interruption Sensitivity to 0.7

ISSUE: Agent doesn't understand Indian terms (lakh, crore)
-----------------------------------------------------------
Fix:
- Add them to Boosted Keywords
- Set Vocab Specialization to "finance"

ISSUE: Call ends abruptly
--------------------------
Fix:
- Increase "End Call After Silence" to 300000ms (5 minutes)

ISSUE: Agent not following the prompt exactly
----------------------------------------------
Fix:
- Make sure you copied the ENTIRE prompt from config/agent-prompt.txt
- Check for any truncation in the System Prompt field
