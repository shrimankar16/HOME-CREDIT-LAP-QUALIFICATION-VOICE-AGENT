# 📞 Phone Call Setup Guide ## Real Voice Calls with Twilio This guide shows you how to set up **actual phone calls** where the AI agent calls customers on their phone numbers. --- ## Step 1: Get Twilio Account (FREE Trial!) ### 1.1 Sign Up Go to **https://www.twilio.com/try-twilio** and create a free account. **Free Trial Includes:** - ✅ $15 credit (enough for ~300 minutes of calls) - ✅ One free phone number - ✅ Voice calls, SMS - ✅ No credit card required for trial ### 1.2 Verify Your Phone Number Twilio will send you a code to verify your own phone number. ### 1.3 Get Your Credentials After signing up, go to **Console Dashboard**: 1. **Account SID** - Looks like: `ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` 2. **Auth Token** - Click "View" to see it 3. **Get a Phone Number** - Click "Get a Trial Number" --- ## Step 2: Configure Your Application ### 2.1 Update .env File Open `.env` file in your project and add: ```env # Server PORT=3001 NODE_ENV=development # Company COMPANY_NAME="Home Credit India" DEFAULT_AGENT_NAME="Priya" DEFAULT_AGENT_GENDER="female" # Twilio Configuration (ADD THESE!) TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx TWILIO_AUTH_TOKEN=your_auth_token_here TWILIO_PHONE_NUMBER=+15551234567 # Webhook URL (your public URL) WEBHOOK_BASE_URL=https://your-domain.ngrok.io/api ``` **Important:** Replace the `xxxxxxxx` values with your actual Twilio credentials! ### 2.2 Install Dependencies ```powershell npm install ``` This will install the Twilio SDK. --- ## Step 3: Make Your Server Public (Using ngrok) Twilio needs to reach your server via a public URL. ### 3.1 Download ngrok Go to **https://ngrok.com/** and download ngrok for Windows. ### 3.2 Extract and Run ```powershell # Extract ngrok.exe to your project folder # Then run: .\ngrok.exe http 3001 ``` You'll see: ``` Forwarding https://abc123.ngrok.io -> http://localhost:3001 ``` ### 3.3 Update .env Copy the `https://abc123.ngrok.io` URL and update `.env`: ```env WEBHOOK_BASE_URL=https://abc123.ngrok.io/api ``` --- ## Step 4: Start Your Server ```powershell npm start ``` You should see: ``` ======================================== HOME CREDIT LAP VOICE AGENT ======================================== Server running on port 3001 ✓ Twilio voice calling enabled ======================================== ``` --- ## Step 5: Make Your First Call! ### Option A: Use the Web Interface 1. Open browser: **http://localhost:3001/call.html** 2. Fill in: - Phone Number: `+919876543210` (your test number) - Customer Name: `Amit Sharma` - Language: `English` 3. Click **"Make Call"** ### Option B: Use API ```powershell curl -X POST http://localhost:3001/api/voice/make-call ` -H "Content-Type: application/json" ` -d '{ "phoneNumber": "+919876543210", "customerName": "Amit Sharma", "language": "english" }' ``` --- ## What Happens During the Call? 1. **Customer's phone rings** 📱 2. **Customer answers**: "Hello?" 3. **AI Agent speaks**: "Hello, good morning. This is Priya calling from Home Credit India. Am I speaking with Amit Sharma?" 4. **Customer**: "Yes, speaking" 5. **AI Agent**: [Presents offer and asks 7 questions] 6. **Conversation continues** until qualification complete or disqualified 7. **Call ends** with appropriate closing message --- ## 🎙️ Voice Features ### Speech Recognition - ✅ Understands natural Indian English - ✅ Handles Hindi conversations - ✅ Converts speech to text automatically ### Text-to-Speech - ✅ Natural Indian female voice (Polly.Aditi) - ✅ Speaks in English or Hindi - ✅ Professional, clear pronunciation ### Call Recording - ✅ All calls are recorded - ✅ Stored in Twilio for 90 days - ✅ Can be downloaded for quality/training --- ## Testing Tips ### Free Trial Limitations With Twilio free trial: - ✅ Can only call verified numbers (add them in Twilio console) - ✅ Calls play a short message: "You have a trial account" - ✅ $15 credit = ~300 minutes of calling ### Verify Test Numbers In Twilio Console: 1. Go to **Phone Numbers → Verified Caller IDs** 2. Click **"Add New Number"** 3. Enter the phone number you want to test 4. Verify with SMS code ### Upgrade to Production When ready for real use: - Add payment method in Twilio - Remove trial limitations - Can call any phone number - Get more phone numbers --- ## Troubleshooting ### "Twilio not configured" **Solution:** 1. Check `.env` file has correct credentials 2. Restart server: `npm start` 3. Look for: `✓ Twilio voice calling enabled` ### "Call failed to connect" **Solution:** 1. Check phone number format: `+919876543210` (include `+` and country code) 2. Verify the number in Twilio console (if trial account) 3. Check ngrok is running ### "Webhook not found" **Solution:** 1. Make sure ngrok is running: `.\ngrok.exe http 3001` 2. Update `WEBHOOK_BASE_URL` in `.env` with ngrok URL 3. Restart server ### "Speech not recognized" **Solution:** 1. Speak clearly and wait for agent to finish 2. Check internet connection (Twilio needs good connection) 3. Try rephrasing your response --- ## Production Deployment ### For Real Business Use 1. **Get Twilio Production Account** - Add payment method - No call restrictions - Lower per-minute costs 2. **Deploy to Cloud** ``` - AWS, Azure, Google Cloud - Use production domain (not ngrok) - Set up SSL certificate ``` 3. **Configure Webhooks** ``` WEBHOOK_BASE_URL=https://your-production-domain.com/api ``` 4. **Get Local Phone Numbers** - Buy Indian phone numbers from Twilio - Better for customer trust - Cheaper local rates --- ## Alternative: Exotel (India-Specific) If you prefer an India-focused solution: **Exotel.com** - ✅ Indian company - ✅ Local phone numbers - ✅ Better Indian accent recognition - ✅ Similar API to Twilio **Setup is similar:** 1.
